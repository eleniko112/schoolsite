# **App Name**: Poti School Hub

## Core Features:

- Class Listing: Display a list of all classes (at least 12) with links to individual class pages. In Georgian.
- Class Pages: Each class page displays the homeroom teacher's first name, last name, and phone number, followed by a list of students. In Georgian.
- Interactive Calendar: Include a calendar table with 30 cells for important dates. In Georgian.
- Lesson Schedule: Display a table with 7 cells for the weekly lesson schedule. In Georgian.
- Image Galleries: Reserved space for images, showcasing school life and activities.
- Dark/Light Mode Toggle: Allow users to switch between a dark and light color scheme.

## Style Guidelines:

- Primary color: Forest Green (#228B22) to evoke a sense of growth and learning.
- Background color: Dark Olive Green (#556B2F) to complement the primary, creating a calm, academic atmosphere, with 20% saturation and brightness appropriate for the dark scheme.
- Accent color: Light Gold (#E6B800) for highlighting important elements, bringing brightness and contrast to the darker palette.
- Body font: 'BPG Boxo', suitable for body text.
- Headline font: 'Playfair', a modern serif with an elegant, fashionable, high-end feel. Note: currently only Google Fonts are supported.
- Use clear and simple icons that are related to education.
- Mobile-friendly design with a clean, organized layout that is easy to navigate.
- Subtle transitions for interactive elements.
